# Grigliato production bot

Проект для Telegram-бота учета продукции grigliato: смены, станки, рейки, упаковки, погонные метры, начисления операторам и наладчикам.

Исходная переписка сохранена полностью в файле [chatgpt-share-transcript.txt](chatgpt-share-transcript.txt).

## Что уже зафиксировано

- Сервер: Ubuntu 22.04, ориентир 1 CPU / 1 GB RAM / 15 GB disk.
- Станков 10: `Г-1`, `Г-2`, `Г-3`, `С-3`, `Г-4`, `С-1`, `Г-6`, `С-4`, `С-5`, `С-6`.
- Смен 4: `№1`, `№2`, `№3`, `№4`.
- День: `08:00-20:00`.
- Ночь: `20:00-08:00`.
- Дата, тип смены и номер смены должны определяться автоматически по дате и времени.
- Брак вводить не нужно.
- Продукцию можно добавлять поэтапно в течение смены.
- На одном станке за смену обычно один оператор.
- Основных наладчиков 2. Общая сумма по всем 10 станкам делится между ними пополам.
- Вспомогательный наладчик не считается по выработке. В отчете вместо суммы писать `Среднесдельная`.
- Роли: админ/мастер, оператор, основной наладчик, вспомогательный наладчик.
- Фото заданий надо сохранять и в дальнейшем распознавать, но запись в производство делать только после подтверждения человеком.

## Предлагаемый стек

- Python.
- Aiogram для Telegram-бота.
- PostgreSQL для базы данных.
- Docker Compose для запуска на сервере.
- OCR/распознавание фото отдельным этапом после базового учета.

## Ближайший план

1. Утвердить оставшиеся правила ввода продукции и отчетов.
2. Собрать схему PostgreSQL.
3. Сделать базовый Telegram-бот: регистрация, роли, смены, станки, ввод продукции.
4. Добавить расчет погонных метров и начислений.
5. Добавить отчет по завершению смены.
6. Добавить хранение фото заданий.
7. Добавить распознавание фото с обязательным подтверждением.
