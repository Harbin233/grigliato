# Расчеты

## Базовые формулы

Количество штук:

```text
pieces = packages * pieces_per_package
```

Погонные метры:

```text
linear_meters = pieces * piece_length_m
```

Заработок оператора:

```text
operator_pay = pieces / 1000 * operator_rate_per_1000
```

Общий заработок основных наладчиков:

```text
primary_setup_total_pay = pieces / 1000 * setup_rate_per_1000
```

Заработок одного основного наладчика, если основных наладчиков 2:

```text
primary_setup_person_pay = primary_setup_total_pay / 2
```

## Пример из переписки

Дано:

- 20 коробок;
- 312 штук в коробке;
- длина одной рейки `0.6 м`;
- ставка оператора `199.18 ₽` за 1000 штук;
- ставка наладчика `93.25 ₽` за 1000 штук.

Расчет:

```text
20 * 312 = 6240 шт
6240 * 0.6 = 3744 пог. м
6240 / 1000 * 199.18 = 1242.88 ₽ оператору
6240 / 1000 * 93.25 = 581.88 ₽ основным наладчикам всего
581.88 / 2 = 290.94 ₽ каждому основному наладчику
```

## Пример с фото задания

Дано:

- 729 упаковок;
- 192 штуки в упаковке;
- длина одной штуки `0.6 м`;
- в задании указано `139888 шт`.

Расчет по упаковкам:

```text
729 * 192 = 139968 шт
139968 * 0.6 = 83980.8 пог. м
```

Расхождение:

```text
139968 - 139888 = 80 шт
```

Правило: если есть расхождение между расчетом по упаковкам и общим количеством из задания, бот показывает оба значения и дает выбрать, какое принять.
