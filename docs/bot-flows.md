# Сценарии бота

## Регистрация

1. Пользователь нажимает `/start`.
2. Бот просит имя и роль.
3. Для оператора можно выбрать свою смену и станок.
4. Новый пользователь попадает в статус `pending`.
5. Админ/мастер подтверждает пользователя.

## Определение текущей смены

1. Бот берет текущие дату и время.
2. Если время `08:00-19:59`, смена дневная.
3. Если время `20:00-07:59`, смена ночная.
4. Номер смены определяется по утвержденному графику.
5. Если пользователь вышел на подработку, он может быть добавлен в другую смену через `shift_members`.

## Добавление продукции вручную

1. Нажать `Добавить рейку`.
2. Выбрать станок.
3. Выбрать рейку.
4. Ввести количество упаковок.
5. Бот считает штуки по упаковкам.
6. Если есть общее количество из задания, пользователь вводит его.
7. Если значения отличаются, бот показывает расхождение.
8. Пользователь выбирает источник количества: упаковки, задание или ручной ввод.
9. Бот показывает подтверждение:

```text
Станок: С-4
Рейка: GL15 мама 75x75 h37 b15
Упаковок: 729
Штук: 139968
Пог. метров: 83980.8
Оператору: ... ₽
Наладчикам всего: ... ₽
Каждому основному наладчику: ... ₽
```

10. Пользователь подтверждает или исправляет.

## Добавление продукции по фото

1. Пользователь отправляет фото задания.
2. Бот сохраняет фото.
3. Бот распознает поля:
   - тип рейки;
   - длина;
   - количество упаковок;
   - штук в упаковке;
   - общее количество штук;
   - код / артикул;
   - цвет.
4. Бот показывает результат распознавания.
5. Пользователь подтверждает или исправляет.
6. После подтверждения создается `production_entries`.

На первом этапе распознавание можно отключить: фото сохраняется, данные вводятся вручную.

## Завершение смены

1. Мастер или наладчик нажимает `Завершить смену`.
2. Бот собирает все записи по смене.
3. Бот считает итоги по станкам, операторам и рейкам.
4. Бот считает общий заработок основных наладчиков по всем 10 станкам.
5. Общий заработок основных наладчиков делится на 2.
6. Для вспомогательного наладчика в отчете выводится `Среднесдельная`.
7. Отчет отправляется получателям.
